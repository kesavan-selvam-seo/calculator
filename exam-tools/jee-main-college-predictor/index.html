How to read JEE Main ranks in JoSAA

OPEN seats: JoSAA opening and closing ranks for OPEN seats are shown using CRL.

Reserved seats: GEN-EWS, OBC-NCL, SC and ST seat ranks are shown using the respective category rank. Do not compare a category rank directly with an OPEN-seat CRL cutoff.

NIT+ Home State quota: NIT+ institutes may have Home State and Other State quotas, depending on the institute. Your state code of eligibility matters; it is not always the same as your current residence.

IITs: IIT admission is based on JEE Advanced rank, not JEE Main rank. This JEE Main planner is for the NIT+ system.

How to check your college chances

  1. Open the official JoSAA Opening and Closing Ranks portal.
  2. Select the counselling round and institute type (NIT, IIIT or GFTI).
  3. Select an institute and academic programme.
  4. Choose the correct seat type/category and gender pool.
  5. Check the quota (Home State / Other State, where applicable) and compare the closing rank with the correct rank list.
  6. Repeat for multiple rounds and programmes. Add a balanced mix of ambitious, moderate and safer choices to your preference list.

JoSAA: Joint seat allocation for IITs, NITs, IIEST, IIITs and Other-GFTIs. For NIT+ system seats, allocation is based on JEE Main rank; IIT allocation uses JEE Advanced rank.

Frequently asked questions

Does JEE Main rank get admission into IITs?

No. IIT seat allocation through JoSAA is based on JEE Advanced rank. JEE Main rank is used for NITs, IIEST, IIITs and Other-GFTIs in the NIT+ system, subject to eligibility.

Should I enter CRL or category rank?

For OPEN seats, compare your CRL. For GEN-EWS, OBC-NCL, SC and ST reserved seats, JoSAA displays the corresponding category rank. Check the seat type before comparing ranks.

What is Home State quota in NITs?

Many NIT+ institutes have Home State and Other State seat pools. The applicable state is based on the state code of eligibility under JoSAA rules, not simply where you currently live.

Are 2026 cutoffs a guarantee for JEE Main 2027?

No. Previous-year opening and closing ranks are only references. Seat matrix, applicant choices, rank distribution, category, programme and counselling rounds can change each year.

Does this page show exact college allotments?

No. It helps prepare your filters and explains how to compare official cutoffs. Final seat allotment is made only through the official counselling process.
