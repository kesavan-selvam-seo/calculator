# Blog Images

Store all CalcuPortal blog images in this directory instead of relying on external image hosts.

Recommended structure:

- `education/`
- `finance/`
- `health-fitness/`
- `travel/`
- `technology/`
- `business-career/`
- `lifestyle/`
- `general-knowledge/`

Use descriptive, lowercase, hyphen-separated filenames such as `percentage-calculation-guide.webp`.
